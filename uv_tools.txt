# CLI tools bootstrap.bash installs with `uv tool install`.
#
# One tool specifier per line (the syntax `uv tool install` accepts), '#'
# comments and blank lines ignored. Each tool gets its own isolated environment
# and its executables are symlinked into ~/.local/bin, which the managed PATH
# puts ahead of the system dirs. To install additional tools, add them below.
#
# The private autocuda package is deliberately absent: it lives behind
# brycelelbach-private and bootstrap.bash installs it in its own best-effort
# step that tolerates a host without repository access.

# Versions for these built-in tools live in src/bootstrap/00_versions.bash.
# Custom lists may add additional tools, but every custom entry must use an
# explicit `package==version` specifier.

# ruff: the linter / formatter.
ruff

# pre-commit: the hook runner projects bootstrapped on this host run locally
# and in CI.
pre-commit

# modal: the CLI for deploying and managing Modal applications.
modal
